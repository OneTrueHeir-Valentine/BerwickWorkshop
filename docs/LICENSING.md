Berwick Workshop's original application source code and documentation are offered under the [MIT License](../LICENSE). That license permits copying, modification and redistribution, including commercial use, as long as the required copyright and permission notice is retained.

## Credited reference material

The MinN-11 material in `reference/BWSDefinitions.py` and `reference/BWSTableEditors.py` retains its original MIT notice in [`reference/MintX-LICENSE.txt`](../reference/MintX-LICENSE.txt). That notice is separate from the copyright notice for Berwick Workshop's own source.

Published Windows packages include a `Licenses.txt` file. It should contain both of these MIT notices and any other notices required for bundled dependencies. The release checker verifies the two repository notices.

## Game content and other artwork

The MIT grant for the editor does not grant permission to distribute *Berwick Saga* game images, extracted sprites, text, translations or other third-party material. Game assets are loaded from a disc image supplied by the user and are not included in the source repository or release archives.

The existing `App/workshop.ico` is present in the repository, but its creator and redistribution rights have not been established. It is not represented as original MIT-licensed project artwork while that question remains open. The icon review is tracked in [Issue #32](https://github.com/OneTrueHeir-Valentine/BerwickWorkshop/issues/32). The application's other bundled dependencies remain subject to their respective licenses.
